Introduction

LineageOS 18.1 (Android 11) on the Microsoft Lumia 950, product talkman. SoC MSM8992, CAF 3.10 kernel. Lunch target lineage_talkman-userdebug.

This thread is for the archienz device tree, not the community ROM in [ROM][UNOFFICIAL] LineageOS 18.1 for Lumia 950 (talkman). That work is the start point. This tree changes the camera path, the torch path, the speaker path, and the health path.

Product: Lumia 950 RM-1104 / board 4VM_08r only. Dual-SIM RM-1118 / 4VM_08d is out of scope. Lumia 950 XL (cityman) is a different product.

One telephone is in use here. Identity: lineage_talkman-userdebug 11 RQ3A.211001.001 eng.deck.20260901.182829. Unofficial zip dated 2026-09-01, then boot-only kernel flashes. Kernel with rear preview: #29.

What works on this telephone

  • Boot to the home screen
  • Display 1440×2560 at 60 Hz (Duke command-mode panel)
  • Wi-Fi QCA6174, factory MAC from DPP
  • Loudspeaker TAS2553 on QUAT_MI2S (PGA 11 dB; quieter than Windows Phone on purpose — 15 dB brownouts an old cell)
  • USB ADB (g_android, not USB configfs)
  • Touch (Synaptics RMI4)
  • GPU Adreno 418 (300 MHz floor on touch, A57 1248 MHz for 1.5 s)
  • Battery percent and voltage — live, not stuck at 50%
  • USB cable charge (SDP 5 V / 500 mA, no USB-PD)
  • Rear camera: Snap live preview and stills (Sony IMX230, HAL1, CCI1 write 0x20, chip 0x0230, CSI lane map 0x0423, mount 90°)
  • Quick Settings flashlight (GPIO 12 led:flash_torch)
  • Bluetooth: pair / LE connect (QCA6174 Rome)

What does not work

  • Cellular / RIL — ril-daemon exits (missing AudioSystem::setErrorCallback). Modem stays OFFLINE
  • GPS — 0 satellites until MPSS is online
  • Front camera — measured (Nokia Ducati module 0x2140, die 0x03BB, 5 MP RAW10), not a CameraId, no HAL
  • Autofocus / OIS — Mitsumi BU24210 at CCI1 0x7c; firmware load is not a lens move. Do not bind lc898212xd
  • Bluetooth media (A2DP) — audio stays on the speaker. Android 11 audio.bluetooth HAL is not packaged
  • Qi wireless charge — not tested
  • Hardware encryption
  • SELinux is permissive

Installation

Full procedure (one RM-1104, from WOA): Install. That install deletes Windows (GPT name Windows) and MMOS. Keep EFS dumps. Keep factory WLAN/BT provision.

  1. Unlock mass storage with WPInternals. Plant LK2ND on EFIESP.
  2. LK2ND fastboot is VID:PID 18D1:D00D (black screen is normal). Not EDL 9008. Volume-down after the Windows logo, not during it.
  3. RAM-boot TWRP, partition, put MBA/MPSS on the modem partition, provision persist from DPP. Do not flash an empty 70 MiB modem image.
  4. Install the unofficial zip you built. Do not upload that zip to a public download site from this tree.
  5. Later camera/kernel updates: boot.img only. Do not wipe userdata. strings boot.img must include mot_imx230 and talkman-cci-scan.

Build on ext4 Linux (this tree is built on SteamOS). Lunch lineage_talkman-userdebug. mka bacon.
