On this telephone (2026-09-05): home screen, display 1440×2560, Wi-Fi, loudspeaker (TAS 11 dB), QS flashlight, live battery percent, USB cable charge. HAL lists CameraId 0 (`mot_imx230`): Snap live preview and stills. Front is measured, not listed. GPSTest empty. Bluetooth pairs; media stays on the speaker. Dual SIM RM-1118 is not this product.

Do not download a public ROM from this page. The unofficial zip is local.
